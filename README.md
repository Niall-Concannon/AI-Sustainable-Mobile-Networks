
# AI for Sustainable Mobile Networks & Energy Intelligence

## Overview

This project aims to develop an AI-powered application to predict energy consumption in mobile telecommunications networks and identify potential energy-saving opportunities.

Using machine learning and data analysis, the application will analyse network activity and energy consumption patterns to highlight opportunities for improving energy efficiency, particularly during periods of low network usage.

An interactive dashboard will be developed to present energy consumption data, predictions and insights through visualisations.

## Objectives

- Analyse and prepare mobile network data for machine learning.
- Develop a machine learning model to predict energy consumption.
- Evaluate prediction accuracy using appropriate performance metrics.
- Identify potential energy-saving opportunities through network usage analysis.
- Develop an interactive dashboard to display energy consumption, predictions and insights.
- Test and evaluate the completed application.

## Technologies

- **Python** – Main programming language.
- **Pandas & NumPy** – Data processing and analysis.
- **Scikit-learn** – Machine learning and model evaluation.
- **Plotly** – Interactive data visualisations.
- **Streamlit** – Dashboard development and deployment.
- **Git & GitHub** – Version control and project management.
